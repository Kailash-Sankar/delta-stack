# Recap

Summarize this session for someone returning to it. Stay within this session.

- Weight by recency. Recent work gets the detail; earlier finished work gets a line or is left out. Anything still open stays in, however old.
- Check before you report. For each PR, branch, CI run, background job, or agent the session touched, look up its current state; don't repeat what it was when last seen.
- End with what is open, split in two: what waits on the user (a decision, approval, or access you lack), and what you can still do yourself. Say so if either is empty.

Keep it short.
